# Rockchip RK3588 notes (measured on the attached board "N1", Android 12)

CPU: 4x Cortex-A76 (cpu4-7, 2.3 GHz) + 4x Cortex-A55 (cpu0-3, 1.8 GHz). dotprod + fp16, no i8mm/SVE.
GPU Mali-G610, NPU RKNPU driver v0.8.2.

## What works / what does not
| Path | Status |
|---|---|
| CPU NEON dotprod (llama.cpp ggml-cpu) | works, the production path |
| llama.cpp OpenCL | rejected: backend only whitelists Adreno/Intel ("unsupported GPU Mali-G610") |
| llama.cpp Vulkan | driver exposes Vulkan 1.1, backend requires 1.2 -> falls back to CPU |
| RKLLM / NPU | driver 0.8.2 is too old for the rkllm runtime (needs >= 0.9.x); only librknnrt present |

## Thread policy
- Never request more threads than cores they can run on: 5 threads pinned on 4 cores -> pp64 collapses to 9.7 t/s (spin-wait).
- Decode: 4 threads on the big cluster (tg 22.3 vs 20.1 with 8 threads).
- Prefill: all 8 cores (pp64 52.9 vs 46.4). Use two ggml threadpools (llama_attach_threadpool).
